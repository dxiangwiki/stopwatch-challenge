# 读秒挑战 · Sticky秒表

> 一个前端趣味魔术小工具，表面是普通读秒挑战，内置隐藏吸附后门。
> 项目灵感：CSS `position: sticky` 吸附思想 + 防抖滑动窗口连击检测。

## ✨ 效果演示

页面外观就是一个极简读秒计时器，支持**毫秒级 3 位小数**（00:00.000）。
看起来是考验人的估时能力，实际可以提前配置目标时间，暂停时自动吸附到预设值。

经典彩蛋玩法：1.314 + 5.200，拼接 `1314520`。

## 🎯 功能

- 高精度计时：基于 `performance.now()`，毫秒精度，`requestAnimationFrame` 渲染
- 吸附配置面板：自定义目标时间、吸附容错范围
- 隐藏触发方式：**快速连续点击标题 3 次**打开配置面板
- 滑动窗口连击判断：复用防抖逻辑，只认定"快速连续点击"，间隔太久会自动清零计数
- 隐蔽设计：标题鼠标指针为默认样式，没有小手 hover 提示，降低可疑度
- 数据持久化：配置自动保存在浏览器 localStorage，刷新页面不丢失

## 📖 使用方法

1. 打开页面，默认展示【读秒挑战】
2. 点击「开始」启动计时，按钮变为「暂停」
3. 再次点击暂停，满足吸附条件就会自动跳到预设时间
4. 调出后台：**快速连续点击顶部标题三下**，弹出吸附配置面板
5. 在面板输入目标时间（如 `1.314`）、吸附范围（如 `0.300`），添加吸附点即可
6. 归零按钮：重置计时器回到 `00:00.000`

> 触发说明：采用防抖滑动窗口判断连击，每一次点击都会向后重置倒计时，只有短时间连续点击才会解锁。

## 🧠 技术巧思

1. **Sticky 吸附思想迁移**：原生 sticky 用于页面滚动吸附；这里挪用到计时器数值吸附。
2. **防抖的非常规用法**：防抖本来用于搜索框、滚动事件做性能降频；
   这里借用防抖定时器机制实现滑动窗口连击检测，用来判断是不是快速三连点击。
3. 高精度时间 API：`performance.now()`，比 Date 获取时间精度更高。
